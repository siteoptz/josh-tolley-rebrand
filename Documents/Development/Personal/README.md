# Personal Development Workspace

This is my personal development environment located in iCloud for cross-device synchronization.

## Directory Structure

- `projects/` - Main development projects
  - `web-apps/` - Web applications and sites
  - `scripts/` - Utility scripts and automation
  - `tools/` - Development tools and utilities
- `experiments/` - Experimental code and learning projects
- `config/` - Configuration files and templates

## Getting Started

```bash
# Install dependencies (when added)
npm install

# Start development
npm run dev
```

## Notes

- This workspace syncs via iCloud
- Use the projects directory for organized development
- Experiments directory for testing and learning
